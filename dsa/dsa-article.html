递归（Recursion）

📝 算法世界的核心思想，万物的开始

在数据结构与算法中，无论是科班出身还是野路子，无论哪个学校第一个逃不掉的知识点一定是递归。我们与其说他是一种算法不如说它是一种思想（虽然我认为所有的算法本质都是由不同的思想演变出来的），其核心的思想还是一种遍历手段？这是我认为的，与以往我们所使用的循环不同，递归讲究后进先出（像栈一样，但其实这里有个核心知识点——递归本身就是在栈上运行的）。他使用了我们编程中自带的内存结构也是我在后面会学习到的一种数据结构"栈"，所以比循环这种没有记忆能力的手段能做的事情更多一些。

大多数讲解递归的例子都讲的是排队，但是我想直接将大家的视角带入一个递归函数中一个变量的视角来理解这个知识点（这里先用 C/C++ 语言，后面有空会更新其他语言的代码的）。 

int fib(int n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    return fib(n - 1) + fib(n - 2);
}

我们参考一下这个斐波那契数列的 C 语言函数代码，我们可以将视角带入 n 这个变量。我们给这个函数的初始 n 为 5，它第一次进入函数后不满足前两行会直接执行第三行，return 的内容是两个函数所以 return 不会直接执行而是进入到两个 fib 函数。进入到第一个 fib 这时候我们的 n 变成了 4，对于第二个函数 n 则变成了 3，然后这两个 fib 会再以每个分成两个 fib 直到两个都减到 1 或 0，然后就开始返回。底层函数也就是 n=1 或者 n=0 时直接返回对应的值，在上一层函数时 return 这一行就会将两个 fib 的返回值加到一起，例如一个 0+1 就变成了返回 1，以此类推。这里再多展开一点方便大家看： 

                              fib(5)
                             /      \
                           3/        \2
                           /          \
                       fib(4)        fib(3)
                       /    \        /    \
                     2/      \1    1/      \1
                     /        \    /        \
                 fib(3)     fib(2) fib(2)   fib(1)
                 /    \     /    \  /   \     |
               1/      \1  1/    \0 1/   \0   1
               /        \  /      \ /     \
           fib(2)    fib(1) fib(1) fib(0) fib(1) fib(0)
            /  \        |      |      |      |      |
          1/    \0      1      1      0      1      0
          /      \
      fib(1)   fib(0)
        |        |
        1        0

所以在这里最后 fib(5) 的返回值就是 5，线旁边的值就是线下面的函数返回的。

那么不难发现递归比较重要的部分就是设置底线，在这里就是 n==1 和 n==0 return 的部分。这就类似我们在循环中的循环条件，其主要目的是一样的——为了防止死循环。但是不同于循环的条件，我们在这里需要注意返回的东西是什么，大多数简单情况中（不需要太复杂的任务处理）就返回本身，我们在近期会围绕简单情况展开，主要目的是为了让大家更好的区分循环条件和递归底层条件之间的区别。斐波那契数列的定义就是"斐波那契数列是一个数字序列，其中每个数字等于前两个数字的总和。这个序列通常从 0 和 1 开始"。所以在这里底层条件就是 i=0 或 i=1，所以递归无非就是不停的给一个新的值带着这个新的值去打开新的一个函数（在这里就是不停的打开新的 fib），然后以此形成循环（很像循环迭代是不是），后面也会将递归与很多新的数据结构相结合来使用。
